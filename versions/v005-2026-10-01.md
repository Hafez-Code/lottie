## التنفيذ

بعد موافقة المستخدم الصريحة على إرسال الكود المتعلق بالدمج، شُغّل Claude عبر ollama launch claude --model deepseek-v4.1-flash:cloud لتنفيذ اختبارات مستقلة. أُعيد التشغيل مع stream-json لإظهار التقدم بعد انتظار صامت؛ اتصل الموديل بنجاح. لا تُنسب الإصلاحات التالية للوكيل: أضاف الاختبارات، وراجعها المنسق وشغّلها وأصلح الكود بنفسه.

- ضمان إنهاء طلب الالتقاط وإزالة مؤقته عند فشل التحقق من الصورة أو كتابة ملفها، بدل ترك طلب MCP معلقًا.
- إرجاع Scene not found عند غياب مسار المشهد بدل خطأ filesystem يتضمن مساره الكامل.
- وصف assets/layers غير الصحيحة كأخطاء بنيوية بدل انهيار فحص المشهد.
- رفض assets/layers/controls غير الصحيحة الناتجة عن API برسالة واضحة مع الحفاظ على المشهد السابق.
- التحقق من صورة capture قبل تكوين image block في MCP.
- تحديد عمق تحليل precomp بـ128 وإرجاع تحليل غير مكتمل صراحة بدل انهيار مكدس الاستدعاءات.
- إضافة اختبارات مراجعة Claude إلى check:workflow بعد مراجعتها وتنقيحها؛ استبعاد فحوص سلوك غير مطلوب لدوال vendor لا يستدعيها التطبيق واختبار يطابق نص المصدر بدل السلوك.
