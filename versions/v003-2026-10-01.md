# v003 — Studio ProMax ومراجعة المستودع المرجعي

التاريخ: 2026-10-01.

## التغييرات

- تغيير الاسم الظاهر إلى Studio ProMax في الرئيسية والتحميل وإعدادات MCP وعنوان الصفحة وقائمة Electron وعنوان النافذة واسم التطبيق في إعدادات الحزم.
- تحديث النصوص الظاهرة في CLI ووصف أدوات MCP وتعليمات الـ agent ووثيقة المنتج.
- إضافة docs/editor-reuse-assessment.md بنتيجة مراجعة diffusionstudio/editor والأجزاء المناسبة والتوافق والقيود؛ لم يُدمج كود المستودع.
- الحفاظ على التصميم الحالي ومعرفات التكامل والتخزين وأسماء أوامر CLI للتوافق، وعلى حقوق النشر الأصلية في LICENSE.

## التحقق

- نجح npm run build (TypeScript وبناء Vite).
- نجح npm run check:workflow: 13 اختبارًا.
- تعذرت معاينة الاسم بصريًا بسبب انتهاء مهلة اتصال أداة المتصفح بالتبويب الحالي؛ لا توجد لقطة شاشة مؤكدة لهذه الدفعة.
- لم يتم إنشاء حزمة تثبيت أو اختبار قوائم Electron داخل نسخة مثبتة.
