# سجل الإصدارات

كل دفعة تعديلات لها ملف مستقل هنا باسم `vNNN-YYYY-MM-DD.md`، يبدأ من `v001` ويزيد بالتتابع. هذا رقم سجل التعديلات، وليس رقم إصدار التطبيق في `package.json`.

كل ملف يذكر:

- تاريخ التعديل والغرض منه.
- الإضافات والتغييرات والإصلاحات المنفذة فعليًا.
- الملفات المتأثرة.
- التحقق الذي تم ونتيجته، وأي قيود أو عمل لم يكتمل.

لا تُسجل الخطط كإضافات مكتملة، ولا تُنسب التعديلات الموجودة مسبقًا إلى دفعة جديدة. يُحدّث ملف الدفعة أثناء العمل، وتبدأ الدفعة التالية بملف جديد دون مسح السجل السابق.
